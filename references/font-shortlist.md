# Проверенный список шрифтов (Google Fonts)

Каждый шрифт в этом списке проверен программно (fontTools, таблица глифов
файла, не название) на реальную поддержку кириллицы — так что можно
использовать сразу без повторной проверки. Если нужен шрифт не из этого
списка, сначала прогони `scripts/check_cyrillic.py "Имя Шрифта"` — многие
популярные жирные дисплейные шрифты (Bebas Neue, Anton, Archivo Black,
Righteous, Bowlby One SC, Caveat Brush) кириллицы не поддерживают вообще,
несмотря на то что выглядят так, будто должны.

Если бренд-текст будет только на английском — можно смело брать что угодно
из Google Fonts без проверки, это ограничение только для кириллицы.

## Как выбирать пару

1. Один заголовочный + один body. Не больше двух шрифтов на весь бренд-бук
   (плюс опционально один акцентный моно/скрипт для капшенов — максимум три).
2. Заголовок и body не должны быть визуально одинаковыми — если оба
   геометричные гротески без характера, пара не читается как решение,
   а как совпадение. Контраст важнее похожести.
3. Подбирай по образу бренда из интервью, не по личному вкусу: "премиальный"
   тянет к серифам или Unbounded, "дружелюбный" — к Comfortaa/Nunito/Rubik,
   "технологичный/AI" — к Golos Text/Onest/IBM Plex Sans/JetBrains Mono,
   "дерзкий" — к Oswald/Unbounded/Exo 2.
4. Всегда называй оба шрифта по имени в самом документе и коротко объясняй
   выбор (1 строка на шрифт) — голое название без обоснования не продукт.
