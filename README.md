# Brand Book Builder

Claude Skill, который за 10-15 минут интервью собирает личный бренд-бук —
готовый одностраничный HTML-документ с палитрой, шрифтами, голосом бренда
и правилами. Без дизайнерского образования, без агентского документа на
40 страниц.

Для соло-фаундеров, маленьких брендов и digital-специалистов, которым нужен
не разговор с советами, а конкретный файл: какой у меня акцентный цвет,
каким шрифтом писать заголовки, как мой бренд не должен звучать.

## Что получаешь на выходе

Один самодостаточный HTML-файл:

- **Палитра** — 5 цветов с ролями (фон, поверхность, текст, вторичный текст,
  акцент), реальные hex-коды, не "тёмно-синий на глаз"
- **Типографика** — заголовочный + текстовый шрифт с обоснованием выбора.
  Все шрифты из шорт-листа проверены программно на поддержку кириллицы —
  не на глаз по названию
- **Голос бренда** — 3-5 принципов, как бренд говорит с людьми
- **Правила и табу** — 3-5 конкретных "никогда не делать X"

Открывается в браузере, печатается в PDF через Cmd+P / Ctrl+P.

## Как установить

1. Скачай этот репозиторий (`Code → Download ZIP` или `git clone`)
2. В Claude (Claude Code, Claude Desktop или claude.ai с поддержкой Skills)
   добавь папку `brand-book-builder` как Skill
3. Напиши в чат что-то вроде: "помоги собрать бренд-бук для моего проекта"

Дальше Claude сам задаст несколько вопросов и соберёт файл.

## Структура

```
brand-book-builder/
├── SKILL.md                     — логика интервью и сборки документа
├── assets/template.html         — шаблон итогового документа
├── references/color-theory.md   — как перевести "дерзкий/премиальный" в hex
├── references/font-shortlist.md — 30 шрифтов с проверенной кириллицей
└── scripts/check_cyrillic.py    — проверка кириллицы для шрифтов не из списка
```
